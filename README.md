# Weather-App-Reminder
Run your python script on a regular basis using Github actions and sends an email to the user.

If you want to use the code you will need to replace a few things.

**Replace the MY_EMAIL with your email. 

**PASSWORD is not your actual password but a Passkey provided in your email security section.

**For an APPID you will need to create an account at https://openweathermap.org where a unique appid will be created FOR YOU.

For Latitude and Longitude you can get them at https://www.latlong.net or any other site that provides this information
